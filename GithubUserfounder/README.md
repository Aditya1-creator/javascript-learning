# GitHub User Finder 🔍

A simple web application to search GitHub users and view their profile information using the GitHub API.

## ✨ Features
- Search GitHub users by username
- Display profile picture, bio, and location
- View followers, following, and public repositories
- Responsive UI built with Tailwind CSS

## 🛠️ Tech Stack
- HTML
- Tailwind CSS
- JavaScript
- GitHub REST API

## 🚀 How to Run
1. Clone this repository.
2. Open `index.html` in your browser, or use VS Code Live Server.
3. Enter a GitHub username and click **Search**.

## 📚 What I Learned
- Fetching data from APIs using `fetch()`
- Working with Promises and `.then()`
- Displaying dynamic HTML using template literals and `innerHTML`
- Handling API responses and errors
